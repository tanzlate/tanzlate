# @tanzlate/core

[![npm](https://img.shields.io/npm/v/@tanzlate/core?color=519ea9)](https://www.npmjs.com/package/@tanzlate/core)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/tanzlate/tanzlate/blob/main/LICENSE)

Shared types and translation helpers for [tanzlate](https://github.com/tanzlate/tanzlate). No
framework, no i18next runtime.

**You probably don't need to install this directly.** It comes as a dependency of
[`@tanzlate/vue`](https://www.npmjs.com/package/@tanzlate/vue) and
[`@tanzlate/vanilla`](https://www.npmjs.com/package/@tanzlate/vanilla). Install it on its own only
to type your own layer on top.

## Install

```bash
npm install @tanzlate/core
```

## What's in it

- `TFunc`, `InputNamespaces` and the key/namespace types the other packages share
- `translation-helpers` — namespace-scoped `t` wrappers
- formatter types
