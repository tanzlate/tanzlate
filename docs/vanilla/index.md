# tanzlate (Vanilla JS)

The **core package** is framework-agnostic. It parses translation strings into an AST and resolves `{{ values }}`.

## Installation

::: code-group

```bash [npm]
npm install @tanzlate/core
```

```bash [yarn]
yarn add @tanzlate/core
```

```bash [pnpm]
pnpm add @tanzlate/core
```

:::
